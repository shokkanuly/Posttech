# Русский и казахский интерфейс

Существующий интерфейс сохранён. Русский включён по умолчанию, Қазақша доступен при входе и в шапке; выбор сохраняется в браузере.

Общий каталог `static/locales/catalog.json` используется браузером и API. Заголовок `Accept-Language: ru-RU` или `kk-KZ` определяет язык отображаемых данных и ошибок. Ключи, роли, статусы и введённые пользователем тексты сохраняют исходное значение.

Миграция `0004_source_translations` добавляет исходный язык документа и сохранённые переводы документа/фрагмента. Правки очищают устаревшие переводы и требуют повторного утверждения с текущей ревизией. AI Jana цитирует только сохранённый утверждённый текст выбранного языка; без источника возвращает безопасное обращение в кадровую службу.

Для проверки используйте исходные синтетические аккаунты из README. Новых способов публичной регистрации нет. 1С и Documentolog остаются неподключёнными.

Проверки: `python -m pytest -q`, `node --test tests/frontend_localization.test.cjs`, Ruff и mypy. [Контракт API](API_CONTRACT.md), [казахская цитата](evidence/localization-kazakh-source.jpg).
