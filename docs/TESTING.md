## Как запустить

```bash
python -m pytest -q                                    # все серверные тесты на SQLite
TEST_DATABASE_URL=postgresql+psycopg://USER:PASSWORD@HOST:PORT/TEST_DB python -m pytest -q   # те же тесты на PostgreSQL
node --test tests/frontend_localization.test.cjs       # переводы и динамический интерфейс (нужен Node.js)
python -m ruff check app tests migrations smoke_test.py dependency_audit.py
python -m ruff format --check app tests migrations smoke_test.py dependency_audit.py
python -m mypy app
python dependency_audit.py --output docs/evidence/dependency-audit.json   # проверка зависимостей
JANAMEN_BASE_URL=http://127.0.0.1:8000 python smoke_test.py               # сквозной сценарий на работающем сервере
```

Каждый тест создаёт собственную временную базу (на PostgreSQL — схему `janamen_test_<uuid>`) и удаляет только её. Не указывайте рабочую базу в `TEST_DATABASE_URL`.

Сценарии MOCK-интеграции в Docker — в [INTEGRATION_DEMO_RUNBOOK.md](INTEGRATION_DEMO_RUNBOOK.md).

## Проверка безопасности

Ручной обзор от 18 октября 2026: аутентификация и права устроены надёжно (PBKDF2 на 600 000 итераций, отзываемые сессии, роль из базы, ограничение попыток входа, токен только в памяти браузера — CSRF через cookie невозможен). По итогам исправлено: правильный ответ теста больше не раскрывается после неверного, добавлены заголовки против встраивания страницы чужим сайтом. Известные ограничения — в [integrations/open-questions.md](integrations/open-questions.md).
