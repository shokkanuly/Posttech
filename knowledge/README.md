# Правила и документы Jana AI

`assistant_rules.json` содержит 12 правил поведения на русском и казахском: утверждённые источники, точные цитаты, права доступа, защита личных данных, безопасный отказ и статус неподключённых интеграций. Приложение загружает список ограничений приватности из этого файла. Остальные требования обеспечиваются серверными проверками; текст документа или вопроса не может их отключить.

`documents/` содержит восемь **синтетических учебных документов** с русским оригиналом и казахским переводом: отпуск, остаток дней, аванс, обучение, уведомления, профиль, согласования и администрирование знаний. Это описание работы демонстрационного приложения, а не официальный регламент работодателя. Суммы выплат, нормы начисления отпуска и юридические сроки не устанавливаются.

`templates/policy.ru-kk.template.json` — заготовка для реального регламента. Вставьте точный текст, проверенный перевод, владельца и фактические реквизиты оригинала. Удалите все заглушки, задайте уникальные `bundle_id`, название и версию, затем поменяйте `kind` с `template` на `document`. Импорт заготовок и незаполненных полей запрещён.

## Проверка и импорт

Из корня проекта с активным виртуальным окружением:

```bash
python -m ml.validate
python -m app.knowledge_files validate knowledge/documents/vacation.json
```

Команда `validate` не подключается к базе. Схемы `assistant_rules.schema.json` и `policy_bundle.schema.json` можно использовать в редакторе или своём загрузчике. Неизвестные поля, флаги утверждения, неподдерживаемые роли, повторные разделы и неполные переводы отклоняются.

Для импорта укажите `DATABASE_URL` нужной локальной базы с актуальными миграциями и адрес существующего действующего кадрового администратора:

```bash
python -m app.knowledge_files import knowledge/documents/vacation.json \
  --actor-email hr.demo@example.com
```

Это локальная операторская команда с доступом к базе, а не публичная регистрация или способ входа. Роль выбранного аккаунта проверяется по базе. Документ, все разделы и запись аудита сохраняются одной транзакцией. В файле нельзя установить утверждение: новый документ всегда **черновик**.

Повторный импорт того же `bundle_id` и содержимого возвращает прежний ID и сохраняет последующие правки HR. Изменённый файл с тем же ID отклоняется: используйте новую версию и новый ID. Команда не перезаписывает имеющиеся документы и не утверждает их автоматически.

## Утверждение и реальные ссылки

1. Войдите в приложение как кадровый администратор.
2. Откройте кадровое администрирование. Просмотрите полный исходный текст и оба перевода импортированного документа.
3. Утвердите текущую ревизию. Пока документ является черновиком, Jana не использует его и не открывает его как источник.
4. Задайте вопрос на нужном языке и откройте цитату. Ссылка использует реальные ID, версию, ревизию и сохранённый язык базы данных.

Разделы с `access_level: manager` доступны руководителям и HR; `hr_admin` — только кадровым администраторам. Переключатель роли и ML-модель не меняют эти ограничения. Правка документа снимает утверждение; старый перевод без замены очищается.

`bundle_id:section_key` — стабильный ключ обучающего файла. Он не является ID источника HTTP API. Настоящие ссылки появляются после импорта и утверждения в приложении.

Обучение и оценка описаны в [ml/README.md](../ml/README.md).
