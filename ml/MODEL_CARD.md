# Карточка базовой модели Jana

- **Задача:** ранжирование разделов кадровой базы по вопросу; не генерация ответа и не оценка сотрудников.
- **Модель:** LogisticRegression, scikit-learn 1.9.1; четыре признака сходства вопроса и источника.
- **Данные:** 100 синтетических вопросов, 8 учебных документов в двух языках; 58/20/22 примера train/validation/test. Персональные записи и реальные регламенты работодателя не использовались.
- **Обучение:** 366 пар. Порог 0.8 выбран по validation при проверке объединённой версии. Настройки, хеши и фактические ошибки — `reports/merge-evaluation.json`.
- **Итог test (после словоформ RU/KK):** 8/16 правильных принятых источников для вопросов с ответом (precision 8/8), 8 безопасных отказов; 4/4 ожидаемых отказов без источника, 2/2 отказов по приватности. Общая точность статуса 14/22, полнота правильного первого источника 50%. Первая версия: 2/16.
- **Смысл оценки:** маленький искусственный набор; результаты не описывают качество на реальных запросах. Показатель 100% среди восьми принятых источников не является достаточным основанием для внедрения.
- **Ограничения:** поиск зависит от совпадения слов и известных алиасов; семантических эмбеддингов и полноценного морфологического анализа нет. Нельзя считать число score калиброванной вероятностью правильности ответа.
- **Защита:** утверждение, активность, язык и роль проверяются сервером до ранжирования; модель не может выдавать права. Цитируется точный сохранённый текст с реальной ревизией. Нет содержимого — нет придуманного ответа.
- **Формат:** проверяемый JSON с конечными ограниченными числами; исполняемые pickle/joblib-файлы не загружаются. Коэффициенты можно переобучить из версионируемых примеров.
- **Рекомендация:** использовать как демонстрационный конвейер, сохраняя штатный поиск по умолчанию. Перед внедрением собрать независимо проверенные вопросы и новые тестовые примеры, улучшить русскую и казахскую нормализацию и повторить оценку по ролям и языкам.

- **Повторная оценка:** test уже использовался ранее; это регрессионный результат, а не новая независимая оценка. Перед внедрением нужен новый набор вопросов.
